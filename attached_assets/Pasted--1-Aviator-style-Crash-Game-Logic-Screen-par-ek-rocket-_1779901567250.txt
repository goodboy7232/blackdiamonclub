## 1. Aviator-style Crash Game

**Logic:**

* Screen par ek rocket udata hai.
* Multiplier `1.00x` se start hota hai aur continuously badhta rehta hai.
* Random point par rocket “crash” ho jata hai.
* User ko crash hone se pehle “Cash Out” dabana hota hai.

**Gameplay Flow:**

1. User bet amount enter karega.
2. “Start” dabayega.
3. Rocket animation start hogi.
4. Multiplier badhega.
5. Time par cashout → win.
6. Late cashout → loss.

**Core Logic Example:**

* Multiplier हर 0.1 sec me increase.
* Random crash point generate.
* Reward = Bet × Current Multiplier.
