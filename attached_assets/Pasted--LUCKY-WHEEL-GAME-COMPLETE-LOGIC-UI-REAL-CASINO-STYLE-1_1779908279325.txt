⚙️ 2. CORE GAME LOGIC (REAL SYSTEM STYLE)
🎯 Step 1: Bet Placement Phase

User selects:

Bet amount
Optional: segment choice (low/high risk zones)
🎡 Step 2: Wheel Configuration

Wheel divided into segments:

Example:

[ 1x | 2x | 0x | 5x | 10x | 0x | 2x | JACKPOT ]
Small reward segments → more frequent
Big reward → rare
🎲 Step 3: Random Selection Logic

System internally:

selected_index = RNG(seed) % total_segments

But real casinos use weighted probability:

Low rewards = high probability
High rewards = low probability
🌀 Step 4: Spin Animation Logic

Important part:

Wheel rotates 3–8 full cycles
Gradually slows down (deceleration curve)
Stops exactly on selected segment
speed → slow → stop (ease-out animation)
💰 Step 5: Reward Calculation
win = bet × segment_multiplier

Examples:

2x → double money
0x → loss
10x → big win
Jackpot → special bonus pool
