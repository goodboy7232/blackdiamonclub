🗼 Tower Climb — Complete 2D Game Logic + UI Structure

Tower Climb ek risk progression / floor survival game ho sakta hai jisme player ek tower ke floors climb karta hai aur har level par safe choice choose karni hoti hai. Jitna upar jaata hai, utna reward multiplier increase hota hai aur risk bhi badhta hai.

1) Core Game Idea

Player ko:

floor by floor upar jana hai
har floor par safe tile choose karni hai
wrong tile → trap / fall / game over
correct tile → next floor unlock
kabhi bhi “Cash Out” karke current reward le sakta hai

Game ka feel:

tension
suspense
greed vs safety
fast decision making
2) Core Gameplay Loop
Step-by-step flow
User bet / entry coins choose karta hai
Tower start hota hai
Floor 1 show hota hai
User tiles me se ek choose karta hai
Safe hua:
next floor
multiplier increase
Trap hua:
lose
game over
User kisi bhi floor par cash out kar sakta hai
3) Floor System

Har floor par:

2–5 tiles ho sakti hain
Sirf kuch safe hoti hain
Baaki trap

Example:

Easy floor
[ SAFE ] [ TRAP ]
Hard floor
[ SAFE ] [ TRAP ] [ TRAP ] [ TRAP ]
4) Difficulty Progression

Tower jitna upar:

safe tiles kam
trap chance zyada
rewards higher

Example progression:

Floor	Safe Tiles	Trap Tiles	Reward
1	2	1	1.2x
2	2	2	1.5x
3	1	3	2x
4	1	4	3x
5	1	5	5x
5) Reward Logic
Reward formula
reward = base_bet × floor_multiplier

Example:

Bet = 100
Reached floor 5 = 5x
Reward = 500
