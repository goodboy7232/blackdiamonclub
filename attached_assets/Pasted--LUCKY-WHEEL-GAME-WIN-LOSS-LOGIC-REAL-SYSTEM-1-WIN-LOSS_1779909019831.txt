🎡 LUCKY WHEEL GAME — WIN/LOSS LOGIC (REAL SYSTEM)
🧠 1. WIN / LOSS KA BASIC RULE

Lucky Wheel me har spin ka result RNG (Random Number Generator) se decide hota hai.

👉 Simple rule:
Wheel stop hua jis segment par → wahi result
Agar tu us segment par bet kiya → WIN
Nahi kiya → LOSS
🎯 Example:

Wheel segments:

[1x | 2x | 5x | 10x | LOSE | JACKPOT]
Result cases:
Wheel → 5x
✔ 5x bet kiya → win
✖ 2x bet kiya → loss
Wheel → LOSS
❌ sab bets lose
Wheel → JACKPOT
💰 high reward win
⚙️ 2. REAL LOGIC (CASINO STYLE)
🎲 Step 1: Segment Setup

Wheel ko multiple parts me divide kiya jata hai:

Low reward segments (1x, 2x) → high probability
Medium segments (5x, 10x) → medium probability
Jackpot → very low probability
🧮 Step 2: Probability System

Har segment ka chance fixed hota hai:

Example:

1x → 40%
2x → 25%
5x → 15%
10x → 10%
Jackpot → 2%
Lose → 8%

👉 Isse balance hota hai game ka “house edge”

🌀 Step 3: Spin Logic
Wheel 3–8 full rotations leta hai
Slowly slow hota hai
Final stop → selected segment

👉 Important: animation pre-decided hoti hai, real-time random nahi

💰 Step 4: Payout Logic
win = bet × segment multiplier

Examples:

2x → double money
10x → 10 times
0x / lose → 0 return
jackpot → special multiplier
