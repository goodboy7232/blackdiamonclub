⚙️ 2. CORE GAME LOGIC (REAL SYSTEM)
🎯 Step 1: Bet Phase

User selects:

Bet amount
Prediction type:
Exact number (e.g., 6)
High/Low (e.g., >3 or <4)
Range (1–3 / 4–6)
🎲 Step 2: Dice Roll System

Single dice:

result = random(1 to 6)

Two dice (advanced version):

result = dice1 + dice2   // 2 to 12 range

👉 Real casino games often use 2 dice for better probability curve.

📊 Step 3: Probability Logic

Dice is NOT uniform in advanced games:

7 (most common sum) → highest probability
2 and 12 → rarest

👉 This creates bell curve distribution


💥 Step 4: Win/Loss Logic
Case 1: Exact Match
if prediction == result:
    payout = bet × 5x to 30x
Case 2: Range Match
if result in range:
    payout = bet × 1.5x to 3x
Case 3: Loss
no match → lose bet
🧠 Step 5: RNG System (Real Casinos)

Real systems use:

Server seed
Client seed
Nonce (round counter)

👉 ensures fairness (no manipulation)
