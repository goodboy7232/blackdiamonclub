# 🎮 Aviator / Crash Game Complete Logic (Real System)

## 1. Core Concept

Crash Game

Game ka base idea simple hai:

* Ek multiplier hota hai: `1.00x → 1.10x → 2.50x → 10x ...`
* Ek “plane/rocket” upar ja raha hota hai
* Kabhi bhi random time par crash ho jata hai
* Player ko crash se pehle cashout karna hota hai

👉 Profit = Bet × Multiplier at cashout
👉 Agar crash pehle ho gaya → loss

---

# 2. Game Round Flow (Step-by-step)

### Step 1: Betting Phase

* Round start hone se pehle 10–15 sec window
* Users bet lagate hain (multiple bets allowed in real systems)

---

### Step 2: Seed Generation (Important part)

Real systems use:

* Server Seed (hidden)
* Client Seed (public)
* Nonce (round number)

👉 Isse “provably fair randomness” generate hoti hai

---

### Step 3: Crash Point Generate Hona

System ek hidden number banata hai:

```
Crash Point = Random value like 1.12x, 2.45x, 8.90x, 50x
```

But distribution fixed hoti hai:

* Mostly low multipliers (1.2x–3x)
* Rare high multipliers (10x+)
* Extremely rare 100x+

---

## 4. Multiplier Growth Logic

Game runtime me:

```
Multiplier = 1.00 + (time × growth rate)
```

But actual system linear nahi hota — exponential easing hota hai:

* Start slow
* Then fast increase
* Then extremely fast near crash

Example curve:

```
1s → 1.10x
2s → 1.35x
3s → 1.80x
5s → 3.00x
8s → 10x+
```

---

## 5. Crash Mechanism

System continuously check karta hai:

```
if (current_multiplier >= crash_point):
    crash()
```

Crash means:

* animation stop
* round end
* who didn't cashout → lose

---

## 6. Cashout System

User anytime click kar sakta hai:

```
cashout_multiplier = current_multiplier
profit = bet × cashout_multiplier
```

Server ensures:

* Only 1 valid cashout per bet
* Latency protection (anti-cheat)

---

# 7. RTP & House Edge (Real Money Logic)

Most real systems have:

* RTP: 94%–98%
* House edge: 2%–6%

Meaning:

* Long term casino always wins slightly
* Short term users can win big

Game is designed to trigger:
