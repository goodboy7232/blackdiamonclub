⚙️ 3. REAL GAME LOGIC (CASINO STYLE)
Step 1: Bet Placement

User selects:

Bet amount
Paylines (1 to 20+ lines)
Step 2: RNG Spin

System generates random outcome:

result = RNG(seed) → symbol matrix
RNG decides final stop position
Every spin independent hota hai
Step 3: Reels Stop Logic
Reel 1 stops first
Reel 2 slightly delay
Reel 3 last stop (dramatic effect)

👉 Isse suspense create hota hai

Step 4: Payline Check

Paylines = winning patterns

Example:

Straight line
Zig-zag
Diagonal
WIN = match(3+ same symbols on active line)
Step 5: Payout System
Low symbols (A, K, Q) → small reward
High symbols (7, diamond, crown) → big reward

Multiplier system:

3 match → 2x
4 match → 10x
5 match → 100x+
